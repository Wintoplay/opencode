# Building and installing OpenCode from this checkout

These notes are local to this checkout. They are intentionally kept out of `README.md` so that `git pull --ff-only origin v2` never conflicts with upstream documentation changes.

## Build and install from this checkout

On Linux or macOS, install Bun and run this from the repository:

```bash
./install-local.sh
```

The script installs dependencies, builds the CLI for the current machine, and copies it to the same user install directory used by the install script. It stamps the build with the CLI package version by default instead of the branch's autogenerated `0.0.0-...` preview version, while keeping the checkout's channel (`v2` here). This lets Console's minimum-version check pass while preserving channel-specific storage. Set `OPENCODE_VERSION` to override the version. Set `OPENCODE_CHANNEL`, `OPENCODE_INSTALL_DIR`, or `XDG_BIN_DIR` to choose a different channel or install destination. It adds the install directory to your shell startup file (`.bashrc`, `.zshrc`, or `.profile`) and prints a `source` command to load the change in the current terminal.

## Upgrading

`install-local.sh` builds and installs the source in the current checkout; it does not fetch updates. From your `v2` checkout, save any local changes, then update and reinstall:

```bash
git pull --ff-only origin v2
./install-local.sh
opencode --version
```

The script picks up the new CLI package version and keeps the `v2` channel automatically.

To add an already-installed binary to `PATH` without rebuilding, run `./install-local.sh --path-only`.
